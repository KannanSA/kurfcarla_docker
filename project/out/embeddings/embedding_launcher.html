📝 Usage Instructions

  1. Click any "Launch Projector" button above to open TensorFlow Projector
  2. Click the "Load" button in the top-left corner
  3. Upload the corresponding vectors_[embedding_type].tsv and metadata.tsv files
  4. Optionally upload sprite.png for visual cluster representations
  5. Use the left panel to color points by different metadata properties
  6. Try different visualization algorithms (PCA, t-SNE, UMAP) in the projector

🎨 Visualization Tips

  • Color by BE_category: See stability regions
  • Color by size_category: Explore size-dependent patterns
  • Color by structural_category: Understand shape effects
  • Use 3D mode: Better separation of clusters
  • Adjust perplexity: For t-SNE, try values between 10-50
  • Search clusters: Type cluster names to highlight specific points
